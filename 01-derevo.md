# Задание 1. Дерево процессов

### 1. Дерево процессов

Для просмотра дерева процессов использовал команду:

`pstree -p | head -40`

В выводе видно корневой процесс systemd(1) и дочерние процессы. Также в дереве присутствует моя пользовательская сессия.

PID текущей оболочки определил командой:

`echo $$`

Результат:

`2241`

Для определения родителя оболочки использовал:

`ps -o pid,ppid,user,cmd -p $$`

Получил:

| PID  | PPID |   USER   | CMD |
| ---- | ---- | -------- |-----|
| 2241 | 2215 | daniil2+ | bash |

### 2. Цепочка процессов

Далее по значению PPID я поднимался вверх по дереву:

| PID  | PPID | Пользователь |             Команда                |
| ---- | ---- | ------------ | ---------------------------------- |
| 2241 | 2215 | daniil2+     | bash                               |
| 2215 | 1286 | daniil2+     | /usr/libexec/gnome-terminal-server |
| 1286 |   1  | daniil2+     | /lib/systemd/systemd --user        |
| 1    | —    | root         | systemd                            |


Таким образом, цепочка от моей оболочки до корня выглядит так:

`bash (2241)`
   
        |
        
`gnome-terminal-server (2215)`

        |
        
`systemd --user (1286)`

        |
        
`systemd (1)`

### 3. Корневой процесс

В корне дерева находится процесс `systemd` с `PID 1`.

У него нет обычного родительского процесса, потому что это первый процесс, который запускается системой и является корнем дерева процессов.

### 4. Количество процессов

Команда:

`ps aux | wc -l`

вернула:

`273`

В это число входит строка с заголовком таблицы, поэтому фактически процессов было `272`.

Большинство процессов находятся в состоянии S. Это означает, что процесс сейчас не выполняется на процессоре, а ожидает какого-либо события. Например, это может быть ожидание ввода, таймера или другого события.
